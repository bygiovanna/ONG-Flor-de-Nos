# 🌸 ONG Flor de Nós

Projeto desenvolvido para a disciplina de Desenvolvimento Front-End para Web do curso de Engenharia de Software.

O projeto consiste em um site para uma ONG fictícia, criado para colocar em prática os conhecimentos de HTML, CSS e JavaScript.

## Funcionalidades

- Navegação em SPA (Single Page Application)
- Página inicial
- Página de projetos
- Formulário de cadastro
- Validação dos campos em tempo real
- Máscaras para CPF, telefone e CEP
- Armazenamento de dados com LocalStorage
- Gráfico com Chart.js
- Layout responsivo

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Chart.js
